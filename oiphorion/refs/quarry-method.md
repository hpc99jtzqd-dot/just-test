## 1. 뽑아낸 방법

한 줄로: **긴 것은 닫지 않고 붙들어 둔다. 거기서 한 덩이를 떼어 낸다. 날짜가 오면 사람에게 넘긴다. 다시 긴 것으로 돌아간다.**

| 장치 | 하는 일 | 근거 |
|---|---|---|
| 채석장으로 두기 | 긴 작업에 끝나지 않아도 된다고 허락한다. 완료 표시를 두지 않는다 | 끊긴 과제가 남기는 긴장. 미완은 동력이다 |
| 잘라 내기 | 두세 번 앉아 닫을 크기로 한 덩이를 뗀다 | 마감이 가까울수록 커지는 동기(가설), 작은 승리, 카프카의 분할 축조 |
| 넘기기 | 끝을 만족이 아니라 날짜와 사람에게 맡긴다 | ~~남이 정한 마감의 효과~~ (근거 철회, 위 정정) → 시험해 볼 장치. 브로트, 연구소의 기한은 사례 |
| 조각의 형식 | 닫힌 조각을 쌓아 전체를 만든다 | 실험형 창작자에게 완성은 도착이 아니라 그만두기로 하는 결정이다 |

지켜야 할 성질 세 가지.

1. **긴 것과 짧은 것을 다른 자로 잰다.** 긴 것은 진행률을 재지 않는다. 짧은 것은 넘겼는지만 본다.
2. **넘치면 늘리지 않고 더 자른다.** 계획은 늘 짧게 잡힌다. 덩이가 예상보다 크면 기한을 미루지 말고 덩이를 줄인다.
3. **빈 곳은 실패가 아니다.** 장성은 구간 사이에 빈 곳을 남기며 쌓는다. 덩이를 넘기지 못한 주는 빈 곳으로 남을 뿐, 벌을 받지 않는다.

## 2. 오이포리온의 말로 옮기기

오이포리온에는 이미 **칸**(하루의 블록)과 **조각**(책상에서 칸을 나눈 단위)이 있다. 여기에 두 층을 더 얹는다.

```
채석장  (몇 달~몇 해, 닫지 않음)      ← 새로 추가
  └ 덩이  (한 주, 넘기면 닫힘)        ← 새로 추가
      └ 조각  (한 번 앉는 25~50분)    ← 지금 책상의 조각을 그대로 씀
돌담    (넘긴 덩이가 쌓인 기록)        ← 새로 추가
```

| 방법의 말 | 오이포리온에서 | 지금 있는가 |
|---|---|---|
| 긴 것 | 채석장 | 없음 |
| 이번 주에 떼어 낼 것 | 덩이 | 없음 |
| 한 번 앉는 단위 | 조각 (`plans[날짜].b[칸].p[]`) | 있음 |
| 딴생각 치워 두기 | 주차장 | 있음 |
| 날짜에 맡긴 끝 | 덩이의 넘길 날 | 없음 |
| 사람에게 맡긴 끝 | 덩이의 받을 사람 | 없음 |
| 쌓인 완성 | 돌담 | 없음 |
| 주 단위 돌아보기 | 일요일 점검 | 있음. 항목만 더한다 |

**기존 규칙과의 관계.** 갈림길(1·2·3선), 모자, 트램펄린, 일요일 점프는 기상 시각으로 판정한다. 채석장 방식은 여기에 섞지 않는다. 덩이를 못 넘겨도 트램펄린은 잃지 않는다. 두 판정을 묶으면 3번 성질(빈 곳은 실패가 아니다)이 깨진다.

## 3. 규칙과 수치

**채석장**
- 최대 3개. 이름과 한 줄 설명만 가진다.
- 완료 단추, 진행률, 마감이 없다. 지우거나 쉬게 할 수는 있다.
- 보여 주는 숫자는 하나다. 지금까지 넘긴 덩이의 수.

**덩이**
- 한 주에 1개. 월요일에 시작해서 토요일에 닫는다. 월~토 판정 주기와 맞춘다.
- 크기는 조각 3개 이하. 조각 하나는 25~50분이므로 합쳐서 150분을 넘기지 않는다.
- 정할 때 네 가지를 적는다.
  - 어느 채석장에서 떼는가
  - 제목
  - 끝의 모양: 무엇이 있으면 넘길 수 있는가를 한 줄로
  - 받을 사람과 넘길 날. 기본값은 토요일
- 닫는 방법은 둘이다. **넘겼음**과 **버렸음**. 둘 다 닫힌 것으로 친다.
- 토요일까지 못 닫았으면 일요일 점검에서 고른다. 더 작게 잘라 다음 주로 보내거나 버린다. 같은 크기로 미루는 선택지는 두지 않는다.

**조각**
- 책상의 조각에 "덩이 조각" 표시 하나를 더한다. 덩이의 진행은 표시된 조각 가운데 `했음`의 수로 센다.
- 어느 칸에 놓을지는 정하지 않는다. 기본 제안은 취미 칸이나 저녁 칸의 마지막 조각, 수업 없는 날의 오전 칸이다.

**돌담**
- 넘긴 덩이 하나가 돌 하나다. 버린 덩이는 돌이 되지 않고, 빈 곳으로도 세지 않는다.
- 덩이를 정하지 않았거나 못 닫은 주는 빈 곳이다. 빈 곳은 그대로 보여 주고 색으로 꾸짖지 않는다.

**4주 뒤에 볼 숫자 (나중 판)**
- 예상한 조각 수와 실제로 쓴 조각 수의 비. 자기 배율을 알면 다음 덩이를 그만큼 작게 자른다.

## 4. 자료 구조

지금 저장 방식(`JOURNEY`)을 그대로 따른다. db가 본체이고 `localStorage`의 `oi.journey.*`는 보조 캐시다. 나중에 저장한 쪽이 이긴다(`savedAt`).

```js
// data/users/{id}/journey/meta/quarries
{ list: [ { id: "q1", name: "소설", note: "문턱과 비탈길", rest: 0 } ], savedAt: 0 }

// data/users/{id}/journey/cuts/{월요일 날짜}
{
  q: "q1",            // 채석장 id
  t: "첫 장면 뒤 차 안 문단",   // 제목
  end: "합평에 낼 수 있는 한 쪽", // 끝의 모양
  to: "합평회",        // 받을 사람
  due: "2026-11-21",  // 넘길 날
  est: 3,             // 예상 조각 수 (1~3)
  state: "open",      // open | handed | dropped
  closedAt: null,     // 닫은 날
  savedAt: 0
}
```

조각에는 필드 하나만 더한다.

```js
// plans[날짜].b[칸].p[] 의 원소
{ m: 25, t: "차 안 문단 초고", n: "", d: 0, r: 0, c: 1 }   // c: 덩이 조각이면 1
```

**주의.** `DESK`의 `clean()`은 조각에서 `m, t, n, d, r`만 남기고 나머지를 버린다. `c`를 여기에 추가하지 않으면 저장할 때마다 표시가 사라진다.

`JOURNEY`의 `api`에 더할 것.

```js
api.quarries()            // 캐시에서 목록
api.saveQuarries(list)    // 캐시 → emit → 온라인이면 dset
api.cut(monday)           // 그 주의 덩이, 없으면 null
api.saveCut(monday, v)    // savedAt 찍고 저장
api.wall()                // 읽어 온 주들의 [{monday, state}] — 돌담 그리기용
```

`connect()`에서 읽는 범위. 지금 하루 기록을 읽는 주들(`from`~오늘)에 맞춰 `cuts/{월요일}`을 함께 읽고, `meta/quarries`를 한 번 읽는다. 기존 `Promise.all`에 끼워 넣어 왕복을 늘리지 않는다.

## 5. 화면

지금 있는 자리에 얹는다. 새 화면은 채석장 목록 하나뿐이다.

**① 머리말의 덩이 띠** (`.signpost` 안, `#nowStrip` 아래)
- 덩이가 있으면: `이번 주 덩이 · {제목} · 조각 1/3 · 토요일에 {받을 사람}`
- 없으면: `이번 주 덩이가 아직 없다` + `떼어 내기` 단추
- 넘길 날 당일: `오늘 넘기는 날이다` + `넘겼음` 단추

**② 책상** (`#deskOv`)
- 조각 줄마다 덩이 표시 토글 하나.
- `조각 더하기` 줄에 `+ 덩이 조각` 단추. 누르면 덩이 제목이 채워진 25분 조각이 들어간다.
- 덩이 조각이 이미 `est`개 이상인데 더 넣으려 하면 한 줄 안내: `세 번 앉을 크기를 넘는다. 덩이를 더 자를까?`
- 막혔을 때 쓰는 빠른 단추 `+ 옮겨 적기 15분`. 이미 쓴 것을 깨끗이 옮겨 적는 조각이다.

**③ 한 주 보기** (`#wkPanel`)
- 요일 목록(`#wkDays`) 아래에 덩이 카드. 제목, 끝의 모양, 받을 사람, 넘길 날, 조각 진행, `넘겼음`·`버렸음` 단추.
- 길 그림(`#wkSvg`)의 토요일 자리에 돌 하나. 넘겼으면 채운 돌, 열려 있으면 윤곽만.

**④ 일요일 점검 두루마리** (`WEEKLY`의 `sunday`)
- `todo`에 세 줄을 더한다.
  - `이번 주 덩이를 넘겼는지 본다`
  - `다음 주 덩이를 하나 뗀다 (세 번 앉을 크기)`
  - `받을 사람과 넘길 날을 적는다`
- 두루마리 본문에 덩이 정하기 양식. 4번 자료 구조의 `q, t, end, to, due, est`를 받는다.
- 열린 채로 일요일을 맞은 덩이가 있으면 두 단추만 보인다: `더 작게 잘라 다음 주로`, `버렸음`.

**⑤ 마감 준비 칸** (`BLOCKS`의 `closing`)
- `todo`에 한 줄: `내일 앉을 덩이 조각 하나를 책상에 올려 둔다`

**⑥ 채석장 두루마리** (새로)
- 머리말에 작은 단추 `채석장`. 누르면 두루마리가 펼쳐진다.
- 채석장마다 이름, 한 줄 설명, 넘긴 덩이 수, 넘긴 덩이의 제목 목록.
- 맨 아래에 돌담. 주마다 돌 하나 또는 빈 곳. 맵·회차 구분선을 함께 그린다.

## 7. 만드는 순서

작게 나눠서 한 단계씩 올린다. 각 단계는 그것만으로 쓸 수 있어야 한다.

1. **자료와 저장.** `meta/quarries`, `cuts/{월요일}`, `api` 다섯 개, 캐시. 화면은 건드리지 않는다.
2. **덩이 띠와 한 주 보기의 카드.** 덩이를 정하고 닫을 수 있다. 여기까지가 최소판이다.
3. **책상의 덩이 조각.** `clean()`에 `c` 추가, 토글, `+ 덩이 조각`, 진행 세기.
4. **일요일 점검과 마감 준비의 항목.**
5. **채석장 두루마리와 돌담.**
6. **나중 판.** 예상 대 실제 배율, `+ 옮겨 적기` 단추, 넘길 날 알림.

각 단계에서 확인할 것.

- 로그인하지 않은 상태(오프라인)에서도 페이지가 돈다. 덩이는 캐시에 남고, 연결되면 올라간다.
- 덩이를 넘기지 않은 주에도 일요일 점프 판정이 전과 같다.
- 조각을 저장하고 다시 열어도 덩이 표시가 남아 있다.
- 휴대폰 폭에서 덩이 띠가 한 줄을 넘쳐도 가로로 밀리지 않는다.

## 8. 하지 않을 것

- 채석장에 완료 단추나 진행률 막대를 두지 않는다.
- 덩이 판정을 트램펄린, 모자, 맵 진행에 묶지 않는다.
- 연속 기록(며칠째)을 세지 않는다. 돌의 수만 센다.
- 한 주에 덩이를 둘 이상 열지 않는다.
- 못 닫은 덩이를 같은 크기로 다음 주에 넘기지 않는다.

## 9. 확인이 필요한 곳

- **db 권한.** 지금 기록은 `data/users/{id}/journey/` 아래 `days`, `plans`, `meta`에 쓴다. `cuts`라는 새 경로에 쓸 수 있는지는 페이지의 db 선언을 봐야 안다. 막혀 있으면 덩이를 `meta/cuts` 문서 하나에 `{월요일: 덩이}` 꼴로 모아 넣는 길이 있다.
- **의사코드 패널.** 칸의 `pseudo`와 `cpp` 패널은 `study_os.cpp`의 `// @anchor` 주석에서 `build.py`가 줄 번호(`ANCHORS`)를 계산해 만든다. 새 규칙을 패널에도 보이려면 `study_os.cpp`에 먼저 넣고 빌드해야 한다. 첫 판에서는 패널을 건드리지 않는 쪽이 안전하다.
- **`todo` 문구를 더하면** `stepsOf()`가 만드는 자세한 순서의 단계 수가 달라질 수 있다. 체크 기록(`oi.steps`)은 단계 번호로 저장하므로, 중간에 끼워 넣지 말고 끝에 덧붙인다.
- **계획 보관 기간.** 책상 계획은 캐시에서 14일이 지나면 지운다. 덩이 조각의 실제 수를 4주 단위로 보려면 덩이를 닫을 때 `cuts/{월요일}`에 `used`(쓴 조각 수)를 적어 둔다.
